헬스케어 LMS 서비스 '버딩크'의 백엔드 리드로서, 기능 개발에 그치지 않고 서비스가 안정적으로 운영되는 것까지 책임졌습니다. 백엔드 동료가 떠난 뒤에는 결제 코드를 인수해 iOS 개발자와 함께 결함을 재현하고 수정했으며, AWS 프리티어가 만료되자 운영 중인 서비스를 새 계정으로 이관했습니다.

build

만드는 것을 좋아하고, 끝까지 만들어 냅니다.

기획부터 출시와 운영까지 1년 넘게 서비스를 만들고 운영했습니다. Java / Spring Boot와 AWS(EC2, RDS, S3)로 수강, 운동일지, 트레이너 구독, QR 발급, 센터 관리 등 핵심 API를 설계하고 구현했습니다. RAG를 실제 서비스에 처음 적용하고 외부 영상 플랫폼을 자체 스트리밍으로 전환하는 등, 서비스에서 생기는 문제도 로그와 실제 데이터로 원인을 찾아 해결했습니다.

communication

직무의 경계를 넘어 소통하는 개발자입니다.

창업팀에서 콘텐츠 제작, 서비스 기획, 백엔드 개발을 모두 경험했습니다. 덕분에 기획자, 디자이너, 트레이너 등 다양한 사람들의 관점을 이해하며 소통할 수 있었고, 팀 Notion에 API 명세서를 만들고 표준 응답 · 에러 형식을 정리해 앱 개발자와의 협업 방식을 개선했습니다. 앞으로도 서비스 전체를 바라보는 시야로 팀에 기여하는 개발자가 되겠습니다.
